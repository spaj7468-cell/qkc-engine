01 · quick start

Two tags and one call.

Drop the script into any page and point QKC.init() at a question bank. The widget brings its own CSS — nothing else to install, nothing to build.

index.html

<!-- 1. the engine (UMD, ~8.5 KB gzip) --> <script src="https://qkc.js.org/engine.js"></script> <!-- 2. your bank, e.g. a school question bank --> <script src="bank-7.js"></script> <div id="quiz"></div> <script> QKC.init({ bank: window.OURI_BANKS[7].algebra[1] }); </script>

04 · bank format

A question is six fields. A bank is an array.

No DSL, no schema registry, no server. Plain objects — the same format the QKC trainer ships its 42 823 questions in. Real item from OURI_BANKS[7].algebra[1] (grade 7, algebra, quarter 1):

fieldtypemeaning
tstringquestion text
ty'choice' | 'bool' | 'input'pick an option / true–false / free keyboard input
ostring[]options — required for choice, shuffled deterministically per seed
cstringcorrect answer (compared trimmed, case- and comma-insensitive)
estringexplanation shown after checking
tpstringtopic — used for filters and per-topic stats
qnumber, optionalquarter/term index inside a container bank
// one real item { "t": "Раскрой скобки: (x + 10)(x + 7)", "ty": "choice", "o": ["x² + 17x + 70", "x² + 10x + 7", "x² + 70x + 17", "x² − 17x + 70"], "c": "x² + 17x + 70", "e": "По формуле (x+p)(x+q) = x² + (p+q)x + pq.", "tp": "Многочлены", "q": 1 }
// init() accepts three shapes: QKC.init({ bank: [ item, item, … ] }); // flat array QKC.init({ bank: { items: [ … ] } }); // { items } QKC.init({ bank: OURI_BANKS[7].algebra[1] }); // quarter slice // …or the full nested container — filter later: const eng = QKC.engine(OURI_BANKS); eng.count({ grade: 7, subject: 'algebra' }); // 460 const test = eng.build({ grade: 7, subject: 'algebra', quarter: 1, count: 10, seed: 'demo' }); // seeded, reproducible
05 · embedding

Any page. Any framework. Or none.

The widget is framework-agnostic DOM — it mounts into an element you own and cleans up after itself. QKC.init() returns { restart, update, destroy, results }.

<!-- no bundler, no npm, no config --> <script src="https://qkc.js.org/engine.js"></script> <div id="quiz"></div> <script> const quiz = QKC.init({ bank: myBank, // [{ t, ty, o, c, e, tp }, …] el: '#quiz', mode: 'normal', // 'normal' | 'exam' | 'sprint' theme: 'bw', // 'bw' | 'light' | 'dark' lang: 'ru', // 'ru' | 'en' (default: autodetect) count: 10, seed: 'spring-2026', // same seed → same quiz onFinish: r => console.log(r.pct, r.perTopic) }); </script>
// React — mount in useEffect, destroy on cleanup import { useEffect, useRef } from 'react'; import QKC from 'qkc-engine'; export function Quiz({ bank }) { const host = useRef(null); const inst = useRef(null); useEffect(() => { inst.current = QKC.init({ bank, el: host.current, mode: 'exam', theme: 'light', lang: 'ru', onFinish: (r) => console.log('score', r.pct), }); return () => inst.current?.destroy(); }, [bank]); return <div ref={host} />; }
<!-- Vue 3 — same lifecycle idea --> <script setup> import { ref, onMounted, onBeforeUnmount } from 'vue'; import QKC from 'qkc-engine'; const props = defineProps({ bank: Array }); const host = ref(null); let inst = null; onMounted(() => { inst = QKC.init({ bank: props.bank, el: host.value, mode: 'normal', theme: 'dark' }); }); onBeforeUnmount(() => inst?.destroy()); </script> <template><div ref="host"></div></template>
// Build a bank in code, validate it, then embed const bank = [ { t: 'typeof null', ty: 'choice', o: ['"object"', '"null"', '"undefined"'], c: '"object"', e: 'Historical bug in JS, kept for compatibility.', tp: 'types' }, { t: 'Arrays are objects.', ty: 'bool', c: 'true', e: 'typeof [] === "object".', tp: 'types' }, { t: '0.1 + 0.2 === 0.3 ?', ty: 'input', c: 'false', e: 'IEEE-754: 0.30000000000000004.', tp: 'numbers' }, ]; const v = QKC.validate(bank); if (!v.ok) console.error(v.errors); else QKC.init({ bank, el: '#quiz', lang: 'en', theme: 'light' });
06 · architecture

How it is built: nothing.

The engine is one ES5-compatible file: seeded RNG (mulberry32), bank traversal, validation, build/score — plus a ~250-line DOM widget that injects its own scoped CSS. The QKC app on top of it is built the same way — vanilla JS, zero dependencies, zero bundlers. The source is the build.

Router

Hash-based screen router in ~60 lines: routes, params, history, deep links (#/quiz?g=7&s=algebra). No router library.

window.addEventListener('hashchange', render)

State

One store object + localStorage persistence with schema versioning. Predictable: every screen is a pure function of state.

state → render(screen) → DOM

i18n

Two flat dictionaries (RU/EN, 412 keys each) + runtime switch. The widget ships its own mini-dictionary — same approach, 25 keys.

t('quiz.next') → 'Далее' | 'Next'

PWA

Service worker (network-first, versioned cache), web app manifest, offline quiz runs from cached banks. Installable, no app store.

sw.js · manifest.webmanifest · offline

a11y

Semantic landmarks, role="radiogroup" options, aria-live feedback, visible focus, prefers-reduced-motion. Keyboard-complete.

Tab / Enter / Space — everywhere

Determinism

Same seed → same quiz: mulberry32 PRNG + FNV-1a string hashing. Tests are reproducible down to option order — that is what makes grading auditable.

build({ seed: 'spring-2026' }) ≡ build({ seed: 'spring-2026' })
07 · npm

npm install qkc-engine

UMD + ESM in one package, dist/ committed to the repo — a git or CDN install works today, exactly like the npm one.

# npm registry npm install qkc-engine # or straight from git npm install github:spaj7468-cell/qkc-engine # or a CDN — no npm at all <script src="https://cdn.jsdelivr.net/gh/spaj7468-cell/qkc-engine@main/dist/qkc-engine.js"></script> <script src="https://qkc.js.org/engine.js"></script>
// CommonJS const QKC = require('qkc-engine'); // ESM / bundlers (Vite, esbuild, webpack, Rollup…) import QKC from 'qkc-engine'; // everything is there: QKC.init({ bank, el: '#quiz' }); // embeddable widget QKC.engine(bank).build({ … }); // headless test builder QKC.engine(bank).score(test, ans); // scoring + per-topic stats QKC.validate(bank); // structural audit QKC.rng(seed); // seeded PRNG
